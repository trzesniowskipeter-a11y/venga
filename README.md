# Venga Cycling Mallorca — strona WWW

Premium bike rental, Port de Pollença, Mallorca.
Statyczna strona (HTML + CSS + JS), hostowana na GitHub Pages.

## Jak działają aktualizacje
Strona jest serwowana przez GitHub Pages z gałęzi `main`.
Każdy commit do `main` publikuje się automatycznie po kilkudziesięciu sekundach.

## Struktura
- `index.html` — strona główna
- `assets/fonts.css` — osadzone fonty (Archivo, Instrument Sans)
- `assets/img/` — zdjęcia (WebP) + logo (SVG)
- `assets/video/` — wideo hero (WebM + MP4)
